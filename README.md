# 霓虹蛇园 · Neon Snake

一款以霓虹花园为主题的浏览器贪吃蛇小游戏。用光点、粒子与柔和的绿色辉光重新演绎经典玩法，并通过三种模式、连击和特殊道具增加挑战。

## 在线体验

**[立即游玩霓虹蛇园](https://wuc-lab.github.io/neon-snake/)**

游戏已通过 GitHub Pages 发布，无需下载或安装。用电脑或手机浏览器打开上面的链接，选择模式并点击「开始游戏」即可。也可以在本仓库的 **Settings → Pages → Visit site** 打开网站。

建议将游戏网址加入浏览器书签，或分享给朋友。浏览器内的最高分仍按设备和浏览器分别保存。

### 发布与更新

GitHub Pages 从 `main` 分支的根目录 `/ (root)` 发布。提交 `index.html` 的修改后，GitHub 会重新部署网站；可在仓库的 Actions 页面查看部署进度。网页仍显示旧内容时，待部署完成后尝试强制刷新。

仓库 README 和文档的修改不会改变游戏玩法。

## 游戏特色

- **三种玩法**：经典漫游、障碍生存、90 秒限时冲刺。
- **渐进挑战**：每收集 6 个普通果实提升一级，移动速度逐步提高。
- **连击计分**：5 秒内连续收集普通果实，倍率最高达到 ×5。
- **特殊道具**：黄金果实、时光泡泡和护盾晶球。
- **成长目标**：单局收集 10、25、50 个果实。
- **本地记录**：三种模式分别保存最高分。
- **响应式界面**：支持键盘、手机方向按钮与棋盘滑动操作。
- **轻量运行**：无需安装依赖，无外部字体或素材请求，单个 HTML 文件即可游玩。

## 快速开始

1. 下载仓库或其中的 `index.html`。
2. 用现代浏览器打开 `index.html`。
3. 选择模式，点击「开始游戏」。

如需通过本地 HTTP 服务运行，可在仓库目录执行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。此方式需要已安装 Python；直接打开文件无需 Python。

## 操作

| 操作 | 键盘 / 触控 |
| --- | --- |
| 移动 | 方向键或 W / A / S / D |
| 暂停 / 继续 | 空格或界面按钮 |
| 开始游戏 | 开始按钮或空格 |
| 重新开始 | R |
| 暂停 | Esc |
| 手机移动 | 方向按钮或在棋盘上滑动 |
| 音效 | 点击右上角音效按钮 |

切换模式会重置当前局。切到后台时，进行中的游戏会自动暂停。蛇不能直接反向移动。

## 模式

| 模式 | 规则 |
| --- | --- |
| 经典漫游 | 无时间限制，收集果实并随等级加速 |
| 障碍生存 | 起始生成晶石障碍，每次升级尝试增加 4 个障碍 |
| 限时冲刺 | 90 秒内争取最高分，碰撞仍可能提前结束 |

没有护盾时，撞墙、撞自身或撞晶石会结束游戏。

## 果实与道具

| 类型 | 效果 | 出现规则 |
| --- | --- | --- |
| 能量果实 | +10 × 当前倍率分，长度 +1 | 棋盘上持续补充 |
| 黄金果实 | +30 × 当前倍率分 | 普通果实累计数为 5 的倍数时尝试生成 |
| 时光泡泡 | 移动间隔变为 1.65 倍，持续 6 秒 | 普通果实累计数为 7 的倍数时尝试生成 |
| 护盾晶球 | 抵挡一次碰撞 | 普通果实累计数为 11 的倍数时尝试生成 |

特殊道具同时最多存在一个，12 秒后消失；触发条件重叠时优先生成护盾，其次减速，最后黄金果实。护盾撞墙会穿越至对侧，撞晶石会移除该晶石，撞自身会取消该步移动。重复收集护盾不会叠加次数。

## 数据与兼容性

最高分通过浏览器 `localStorage` 保存在当前浏览器中，不会上传到服务器，也不会跨设备同步。清理站点数据会删除记录；浏览器禁止本地存储时仍可游玩，但记录可能无法持久保存。

建议使用更新版本的 Chrome、Edge、Firefox 或 Safari。音效依赖 Web Audio，绘图使用 Canvas `roundRect`。旧浏览器兼容性与完整移动端体验尚未全面验证。

## 项目背景

项目起源于「制作一个画面精美、足够耐玩的贪吃蛇小游戏」的需求，借助 Codex 完成设计、实现与初步验证。视觉主题强调「保持好奇，保持生长」，用经典规则降低上手成本，以连击、障碍与道具提供重复挑战的动力。

更多说明见 [设计文档](docs/DESIGN.md) 和 [验证记录](docs/TESTING.md)。
