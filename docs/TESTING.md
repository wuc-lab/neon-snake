# 验证记录

## 已完成检查

在初始开发期间进行了 JavaScript 语法检查，并使用模拟 DOM 的 Node.js 环境检查以下核心逻辑：

- 普通果实计分与长度增长。
- 连续收集触发连击倍率。
- 直接反向输入被拒绝。
- 两次合法转向按队列执行。
- 无护盾撞墙结束游戏。
- 护盾撞墙穿越边界并消耗护盾。
- 暂停与恢复状态切换。
- 生存模式生成障碍且不与初始蛇身重叠。

本地 HTTP 预览入口返回 200，HTML、CSS 和 JavaScript 请求成功。开发测试脚本保留在原开发工作区，未包含在当前单文件仓库中；上述记录不是本仓库 CI 的运行结果。

## 手动回归清单

修改后建议检查：

- [ ] 三种模式都可开始、结束和重新开始。
- [ ] 键盘、按钮和滑动控制方向正确。
- [ ] 快速连续输入不会造成直接反向。
- [ ] 普通果实与黄金果实正确计分。
- [ ] 超过五秒未吃普通果实时倍率回到 ×1。
- [ ] 减速在六秒后结束，特殊道具在十二秒后消失。
- [ ] 护盾分别处理边界、自身和晶石碰撞。
- [ ] 冲刺倒计时在暂停时停止，90 秒后结束。
- [ ] 隐藏页面时自动暂停。
- [ ] 三种模式的最高分分别保存，刷新后仍可读取。
- [ ] 本地存储被禁用时仍能游玩。
- [ ] 手机纵向屏幕中棋盘、按钮和计分清晰可见。
- [ ] 静音与开启音效正常。
