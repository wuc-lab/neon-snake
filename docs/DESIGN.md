# 设计背景与实现说明

## 目标与视觉

霓虹蛇园围绕「画面精美、足够耐玩」的目标设计。暗色棋盘搭配荧光绿色蛇身与能量果实，特殊道具以金、蓝、紫色区分。粒子反馈、音效与成长目标为收集动作提供即时反馈。

桌面布局将棋盘与模式、道具说明并列；窄屏布局改为纵向排列并提供方向按钮。全部视觉通过 CSS 和 Canvas 绘制，无需图片素材。

## 玩法取舍

经典模式提供熟悉的基础规则；生存模式增加路径规划压力；冲刺模式以 90 秒限制形成短局挑战。五秒连击窗口鼓励主动追逐果实，同时最高分和收集目标提供重复游玩的动机。

特殊道具随机出现在未被蛇、晶石、果实或其他道具占据的格子中。障碍生成会避开蛇头附近，但不执行路径连通性检查，因此生存模式不保证每次生成的路线都同样容易。

## 实现结构

- 棋盘为 30 × 30 格，Canvas 内部分辨率 720 × 720。
- 蛇由坐标数组表示，头部位于数组首位。
- requestAnimationFrame 驱动绘制；累积时间控制离散移动。
- 最多缓存两个合法转向，避免快速输入丢失，同时禁止直接反向。
- 运行状态包括 ready、playing、paused、over。
- 普通果实触发成长、连击和等级变化；特殊道具单独处理。
- Web Audio 生成短音，不加载外部音频文件。
- localStorage 键为 neon-snake-records，按模式保存最高分。

本仓库将样式与脚本内联到 index.html，便于下载和直接打开。修改时可搜索 reset、tick、draw、frame、turn 等函数定位相应逻辑。

## 当前边界

没有账户、服务器排行榜、联网对战或跨设备存档。没有全面的无障碍游戏操作支持。程序已有部分逻辑检查，尚未完成全面浏览器与移动设备验证。详见 TESTING.md。
